# 字幕规范与质检

## 两个真相分开

- **剪辑**说了算「留哪些话、在什么时候」——时间的唯一真相；
- **字幕**说了算「屏幕上显示什么字」——显示的唯一真相。

所以一屏字幕存「对应的词 / 台词 id + 显示文字」，**不单独存秒数**，时间每次从剪辑结果现算。镜头增删后能精确指出「第 7、第 12 屏的词被剪掉了」，而不是笼统的「字幕可能过期」。字幕可以和转录不同：加标点、去口头禅、专名正式写法。

## 来源

- 短剧字幕**逐字取自剧本台词**，不用模型听写；
- 系统音 / 画外音按项目约定加标记（例如【】）并区分颜色；
- 原生字幕（画面里本来就有的）和后期字幕严格区分，不冒充。

## 分屏规则

- 按句分屏，一屏一句；竖屏每行建议 ≤14 个汉字，最多两行；
- 长句在标点或语义停顿处断开，不在词中间断；
- 每屏显示时长 ≥1.1 秒；放不下时压缩停顿，不压到读不完；
- 说话人切换时换屏。

## 质检清单（ASR 来的字幕尤其要跑）

1. 长行自动拆分；
2. 标点标准化（中文用全角，句末不留逗号）；
3. 填充词 / 重复词过滤（嗯、啊、那个、就是就是）；
4. 幻觉文本与噪声标签检测（「字幕由 xx 提供」「请不吝点赞订阅」「[音乐]」）；
5. 文本密度过高检测（每秒字数明显超过语速）；
6. 时间偏移校正、最短时长、相邻间隙过小时合并；
7. 专名用词典统一写法（人名、地名、品牌）。

## 样式

位置避开画面主体和平台 UI（竖屏底部预留约 15%），描边或半透明底条保证可读；字幕最后叠在所有叠层之上。
