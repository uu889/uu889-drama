# 对标拆解与节奏档案

把别人的成片拆成**能复算的数字**和**能迁移的机制**，再拿来和自己的剧比。

## 边界

- 只分析用户提供或有权使用的材料；
- 报告和交给其他环节的内容**不写对标的剧名、人名、台词和独特桥段**，只写机制；
- 只负责量、拆、比，剧本和分镜由各自环节修改。

## 1. 登记本轮问题

先写下要回答的问题（「我们第 1 集为什么留不住人」「打戏节奏差在哪」），问题决定抽哪几集、看哪些维度。

## 2. 测量（来自切点检测 + 字幕 / 转写）

| 维度 | 指标 |
|---|---|
| 集长结构 | 每集时长、首集是否加长 |
| 开场 | 第一个钩子出现的秒数、开场方式（冲突 / 反常 / 奇观 / 悬念） |
| 镜头 | 平均镜长、镜长分布、近景类镜头占比 |
| 对白 | 对白密度（字/秒）、有人说话的时长占比、画外音占比 |
| 情绪触点 | 相邻两个触点的最大间隔（触点 = 一句冲突台词、一个改变局面的动作或一条新信息） |
| 反转 | 每集有人施压的反转次数 |
| 集尾 | 停在峰值还是余韵、下一集怎么接 |
| 画幅与形态 | 横竖屏、实拍 / 漫剧 / 3D |

每项分开写：直接观察、解释、未知。数字只回报事实，不下判断。

## 3. 提炼机制

几部对标都出现、又说得清解决观众什么问题的做法，写成机制候选：观众状态、戏剧问题、可选机制、可见效果、适用条件、失效边界、**不得复制的部分**。只在一部里出现的标「单一来源」。

## 4. 节奏档案（用户接受后才生效）

```
first_hook_seconds: 3          # 开场多少秒内给第一个钩子
beat_interval_seconds_max: 8   # 情绪触点最大间隔
opposed_reversals_per_episode_min: 2
target_avg_shot_seconds: 3.5
close_shot_share_min: 0.45     # 近景类镜头占比下限
end_on_peak: true              # 停在峰值，不接余韵
```

## 5. 和本项目对照

把本项目的剧本 / 分镜（计划值）或成片（实测值）用同一把尺子量，出差距表；每条差距问用户是不是有意为之，不是有意的交给对应环节改。

## 6. 出片验证

改完挑一段代表差距的戏，用同一模型生成前后两版、每版至少两次，再量一遍；看画面时去掉版本标记再判断。
