# 画面一贯性

AI 视频最容易出问题的是「同一个人每个镜头长得不一样、画风忽然变了、场景陈设对不上」。按下面做，并且每一步都用工具落实（工具会自动套用设定，但前提是你把名字写对）。

## 1. 一个画风基调

- 第一次出图前用 `set_look` 写一段画风基调：媒介（实拍 / 3D / 国漫 / 日漫 / 水墨…）+ 色调 + 光影 + 质感 + 镜头感，40–120 字，具体到能复现。
  - 好：「电影感写实，35mm 胶片颗粒，低饱和冷青色调，侧逆光勾边，浅景深，皮肤质感真实」
  - 差：「好看、高级、电影感」
- 全片只用这一段。用户要换风格 = 从头重做设定图和关键帧，不要中途混用。
- 画幅（9:16 / 16:9…）和分辨率全片统一。

## 2. 设定图先行

- 出场两次以上的角色、产品、主要场景，先 `create_reference` 出设定图，同一回复里并行出。
- 外观描述要写成「下一个镜头能照着画」的锁面：
  - 角色：年龄、脸型五官、发型发色、体型身高、标志特征（痣、疤、眼镜）+ styling 写服装颜色材质与配饰。
  - 场景：空间布局、主要陈设与位置、门窗方向、时间段、主光方向与色温。
  - 道具：形状、尺寸、颜色、材质、Logo / 刻字位置。
- 换造型（换装、受伤、变身）= 新设定，名字写成「林小雨-晚礼服」，不要覆盖原设定。

## 3. 出场必带设定

- 每次 `generate_image` / `generate_video` 都把出场的设定写进 characters / scene / props，或在提示词里写 `@名字`。工具会自动附设定图、写【外观锁定】【场景一致】【画风一致】。
- 提示词里不要再自己描述一遍外貌（容易和设定冲突），只写动作、表情、位置、镜头。
- 名字必须和设定里的完全一样（「林小雨」不能写成「小雨」）。

## 4. 关键帧优先

- 多镜头成片：先给每个镜头出关键帧（镜头开始那一刻），检查长相 / 服装 / 场景一致后，再用 first_frame_asset_id 图生视频。
- 关键帧写清景别机位与站位，同一场戏保持轴线（谁在左、谁在右不换边）。

## 5. 接上一镜

- 同一场戏的连续动作：下一镜 first_frame_asset_id 填上一镜的视频 id（自动取最后一帧）。
- 接戏代数有上限（默认连续 2 代）：每代图生视频都会放大压缩块、锐化、偏色。超过上限工具会把结尾帧改作参考图并告诉你，这时最好重新出一张关键帧作首帧。
- 跨场景、跨时间、跨机位大切换不要接。

## 6. 质检对照设定图

- 关键帧和片段出来后用 `inspect_media`，question 里点名要对比的设定（如「林小雨的发型和服装是否与设定图一致」），工具会把设定图一起给你看。
- 不一致（脸、发型、服装颜色、场景布局、画风）就重做一次；同一个问题重做两次还不行，改写提示词（减少动作、拉远景别）而不是继续抽卡。
