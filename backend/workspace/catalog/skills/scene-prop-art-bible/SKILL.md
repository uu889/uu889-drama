# 场景与道具美术圣经

为剧本里的场景和叙事道具写可直接出图的设定，保证跨镜、跨集的空间和物件一致。

## 场景条目

每个场景写：

1. **一致性锚点**：3–5 个永远在、能一眼认出的固定元素（例：左墙一排铁皮柜、窗外霓虹招牌、地面绿色水磨石）；
2. **空间布局**：入口、窗、主要家具的相对位置，人物通常站或坐在哪；
3. **光照状态变体**：同一场景按剧本需要的时段写成几个状态（白天 / 黄昏 / 夜 / 雨夜 / 停电），每个状态写光源、方向、色温；剧本用到的光照状态必须在这里登记；
4. **白板图提示词**：`no people, no hands, empty scene`，用于做场景参考图——带人的场景图会把人带进每一镜；
5. **定调图**：每个场景先出一张中远景作为色调、光线、质感的基准，其余镜头只取它的色调光线，不取构图。

## 道具条目

只登记**叙事道具**（推动剧情、需要跨镜认出的东西），全剧 ≤8 件。每件写：

- 外观锚点（颜色、材质、形制、尺寸参照：「比手掌略大的黑色皮面笔记本」）；
- 状态变体（新 / 旧 / 破 / 染血 / 打开 / 合上）及出现在哪几集；
- 持有人与位置变化；
- 白板图提示词：纯白或中性背景、单件、无手。

## 尺度参考

容易画错大小的东西（剑、手机、门、车）写一句和人体的比例关系。

## 批量共用

同场景 + 同光照状态的镜头归为一批，共用同一张环境参考图——这是 AI 版的顺场表，能显著减少场景漂移。

## 场景数量

主场景控制在 4 + ⌈集数 ÷ 10⌉ 以内；只出现一次的场景先看能否并入已有场景。
