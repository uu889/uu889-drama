# 连续性锁与场景站位

## 连续性锁

需要跨镜保持的造型、道具状态，写成**一条能原样贴进提示词的短语**，叫「锁面」。

```
LOCK-江晨-常服《江晨松枝绿常服》
- 生效镜头：EP001-002、EP001-003、EP001-007
- 锁面：pine-green lapel service jacket
```

规则：

- 生效镜头的关键帧提示词和视频提示词里，**锁面逐字出现**，不因为「参考图会交代」就省略；
- 颜色、材质、形制这类跨镜不变的事实不靠模型记忆；
- 状态变化（衣服湿了、受伤了）开一条新锁，写清从哪一镜开始生效；
- 镜头里需要一致但还没登记的物件（四镜都出现的一支笔），逐镜用完全相同的描述钉住，并提醒补登记。

## 场景站位（一场拍多镜之前先写）

1. **固定锚点**：场景里不动的参照物（长桌、门、窗、床）；
2. **相对位置**：每个人相对锚点和彼此在哪（「周在桌后正中坐，江在桌前右侧站，两人隔着桌子」）；
3. **轴线与 working side**：两人对话的轴线在哪，机位留在哪一侧；
4. **哪一镜改变站位**：只有剧本里有移动才改；人物移动只服从剧本，不为了连续性补动作。

每一镜的起点、终点写「锚点 + 人物关系」，视线写看向谁或什么；关键帧再把它翻译成本镜机位下的前后景、左右和中间隔着什么。

## 跨镜检查（相邻两镜）

先判断两镜关系：同一连续时空 / 剪接（换景别、正反打）/ 时空跳跃。连续关联时检查：

- 人物左右位置、朝向、视线没有无故翻转（轴线）；
- 持物手、道具数量、道具状态链连续（段内 + 跨段）；
- 衣着、伤、湿、脏的程度沿时间线推进，不会「自动变整齐」；
- 光源方向和时段一致。

换场或时间跳跃时重新锚定，写明新的站位。

## 电影语法提醒

- 一场戏优先用建立镜头交代空间；
- 避免两个特写之间直接硬切（观众会失去空间关系）；
- 复杂群戏先锁空间锚点和轴线，再决定景别变化。
