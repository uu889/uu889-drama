# 解说文案

把一个主题或关键词扩写成短视频旁白，每段对应一个画面。

## 结构

- 叙事逻辑：**引起共鸣 → 提出观点 → 深入解释 → 给出启发**；
- 每段传达一个有价值的观点或洞察，像同一个人在连续分享；
- 最后一段给行动建议或启发，让观众觉得「值得看」。

## 开场多样性（最重要）

- 每段的开场按内容本身自然选择：陈述、场景、感叹、观点、提问、对比、故事都可以；
- **禁止任何固定句式**：不要「第 N 段总以 X 开头」，不要反复用同一个连接词开头；
- 全文里任何一个词（「其实」「有时候」「你有没有」）作为开场出现超过一次，就是失败的创作；
- 优先用观点、场景、故事衔接，不靠连接词起句。

## 语言

- 像和朋友聊天：通俗、真诚、有启发，不学术、不说教、不煽情过度；
- 输出语言跟随用户输入的语言；
- 每段字数控制在要求范围内，写完自检字数下限；
- 不用网址、表情符号、数字编号，不用空话套话；
- 句中用中文标点表达停顿和语气，段末不加标点（便于 TTS 断句）。

## 引用

- 科学 / 健康可引用权威期刊或研究，心理 / 哲学可引用思想家观点，国学可引原文，文史可引经典；
- 引用不是必须的，按主题判断；**不得编造来源**；自然融入，不堆砌。

## 配图提示词（每段一张）

- 英文 50–100 词，结构：场景 + 人物动作 + 情绪 + 象征元素；
- 用象征把抽象观点画出来（路 = 选择、锁链 = 束缚、门 = 机会），避免过于字面；
- 画风由项目统一附加，不在每条里重复写。
