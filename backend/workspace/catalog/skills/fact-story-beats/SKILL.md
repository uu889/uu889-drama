# 真实趣闻动画短片

55–70 秒竖屏，讲一个**有物理因果、能拍出来**的真实冷知识或历史小故事。故事、角色、旁白都必须是自己原创的；参考别的频道只研究手法，不复制脚本、角色、镜头，也不在旁白里提它的名字。

## 选题

- 一个让人意外的真实故事，有可见的因果（东西塌了、爆了、飞了、走错了）；
- 一个日常类比能把原理讲明白；
- 在脚本开头写下事实和来源，笑点必须是查证过的真事。

## 节拍公式（约 3.7 个英文词/秒，中文约 4–4.5 字/秒）

1. **Hook**：一句话说出荒诞的事实（「七十四个士兵，只是走过去，就把一座铁桥踩塌了」）；
2. **Setting**：年份、地点、当时的骄傲；
3. **Action**：三四拍逐步升级，每拍比上一拍大一点；
4. **Snap**：断裂的那一刻；
5. **冷面双句**：「幸好…… / 不幸的是……」；
6. **Explanation**：一个原理 + 一个日常类比（荡秋千的孩子）；
7. **Consequence**：由此产生的规则或改变；
8. **Callback twist**：回扣开头的反转结尾。

**不在画面上描述观众已经看见的东西**；旁白一个稳定语气。

## 画面与声音

- 一切按配音的词时间对齐：画面反应落在对应词之前 0–3 帧；
- 先锁定画面时长，再做音效和配乐；画面改了时间就重做声音；
- 停顿镜也要缓慢推进，重音词稍快；冲击时短促抖动后衰减；
- 换地点 / 时间用交叉溶解，钩子之后可以一次白闪；
- 混音参考：旁白不动，音乐 +3 dB 起、音效 -6 dB 起，按实际听感调。

## 检查

和参考画面并排对比色彩、光、墨线、景深、构图；逐帧查黑帧、白帧、冻帧、跳帧和响度。
