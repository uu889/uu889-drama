# Seedance 视频提示词

## 先确认版本

- **2.0**：单段 4–15 秒；图片 ≤9、视频 ≤3（总 2–15 秒）、音频 ≤3（总 ≤15 秒），总文件 ≤12；不接受写实真人脸素材；
- **2.5**：单段最长约 30 秒，适合长叙事与时间戳；
- 用户没说就问一次「2.0 还是 2.5」，回答后保持在同一个任务里，不因为用户只回了「16:9」「1080p」就当成新任务。

## @ 引用：每个素材都要写用途

```
@图片1 作为首帧        @图片2 作为尾帧
参考 @图片3 的人物形象   场景参考 @图片4
参考 @视频1 的运镜效果   参考 @视频1 的动作编排
背景BGM参考 @音频1       旁白音色参考 @视频2
穿着 @图片5 的服装       字体参考 @图片6 的字体
```

只写「参考 @视频1」是最常见的错误——必须说清参考的是运镜、动作、特效、节奏还是声音。上传了几张图，每张都要有归属。

## 结构

```
[主体 / 人物（@引用）] + [场景] + [动作] + [运镜] + [分时段] + [转场 / 特效] + [音频] + [风格]
```

10 秒以上用分时段：

```
0–3秒：开场画面、运镜、动作
3–7秒：发展
7–12秒：高潮或关键动作
12–15秒：收尾、定格
```

## 短剧片段写法

```
画面（0–5秒）：特写@图片1 通红的眼眶，手指死死指着对方，眼泪砸在衣襟上。
台词1（@图片1，哽咽怒吼）："你到底想骗我什么？"
画面（5–10秒）：@图片2 双手紧握信封往前递，镜头扫过桌上的旧照片。
台词2（@图片2，急切）："我没有骗你！这是他托付我的！"
画面（10–15秒）：信封打开，@图片1 瞬间僵住，眼神从愤怒转为震惊。
音效：急促钢琴 + 抽泣声。全程不生成字幕。
```

## 其它能力

- 视频延长：`将 @视频1 延长 5 秒`（生成时长选新增部分）；也可向前延长；
- 视频编辑：改剧情、换角色、加元素（`视频1 中的女主换成 @图片1，动作完全模仿原视频`）；
- 漫画演绎：`将 @图1 以从左到右从上到下的顺序进行漫画演绎，保持台词与图片一致`；
- 一镜到底：明确写「全程不要切镜头」；
- 音乐卡点：多张图 + 参考视频的节奏。

## 避坑

1. 同一段不要同时要求「固定镜头」和「环绕镜头」；
2. 4–5 秒里不要塞太多场景，复杂度跟时长匹配；
3. 一定写音频（台词、音效、配乐或静默），它能明显提升质量；
4. 剧情只导演不编剧（见剧情保真锁）。
