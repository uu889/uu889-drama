# 多图合成提示词

多图编辑 / 多图参考模型（GPT Image、Qwen Image Edit、Seedream、Gemini 等）出角色定妆、关键帧时，按「图 N 管什么」逐句写，实测比堆砌关键词更能还原服装、避免照搬白模线条。

## 写法

按**实际传入模型的图片顺序**称「图1 / 图2 / 图3」，每张图一句：

- **角色设定参考**：「图1 是同一角色的多个视角与细节，不是多个不同人物。保持脸型、五官、发型、发色、肤色及服装配饰一致；只作为角色参考，成品布局按本次要求。」
- **人物**：「人物为图1中的人，保持脸型、五官、发型（短发 / 长卷发…）和发色一致。所有裸露皮肤（包括服装镂空处）的肤色与脸部统一。」没给服装图时加一句「保留图1人物原有服装，不复制姿势图的外观」。
- **服装**：「让人物穿上图2展示的整套服装和配饰，每件单品的颜色、款式、面料与配饰都以图2为准。」
- **姿势**：「人物的姿势与图3一致；图3只提供姿势，不复制其中白模的外观、线条或材质。」用深度图时写「图3是深度图，只取人体姿态与空间关系」。
- **场景 / 道具**：「背景场景参考图4的布局与固定元素」「手中拿着图5的道具，形制颜色以图5为准」。

最后一句写画风与画面要求：画风预设 + 画幅 + 景别 + 光线。

## 无脸情况

只有服装和姿势、没有人像时，写清「生成一个新的、符合角色设定的人物」，并给出年龄、性别、发型等描述，避免模型把白模的脸当成人脸。

## 照片类与绘画类

- 照片类画风（写实人像、杂志、胶片）：强调真实皮肤与织物细节；
- 绘画类画风（二次元、厚涂、手办）：强调线条、色块与材质表现，不写「真实毛孔」。
