# 分镜与冻结关键帧

## 三层结构

- **段**：一次视频生成，≤15 秒（按目标模型上限改），不跨场次；
- **切**：段内 2–5 秒的镜头，每切认领剧本里连续的几个节拍；
- **关键帧**：每切一张，主关键帧钉在段的 0 秒，子关键帧钉在各自切点。

剧本的每个节拍被恰好一个镜头认领，顺序不乱；剧本里每个场景都要有镜头承载，确实不拍的写明理由。

## 每镜必写

| 字段 | 写法 |
|---|---|
| 职责 | 这一镜唯一要让观众看清的事 |
| 来源 | 剧本场景 ID + 短引文 |
| 时长 | 由声音事件和动作推出（见对白估时） |
| 景别 / 机位 | 中文景别词写进关键帧提示词 |
| 运镜 | 逐镜按目的选，写行为和理由；**固定也写理由** |
| 起点 | 人物姿态、双手、持物、相对锚点的位置、视线 |
| 唯一动作 | 起点到终点的那条可见状态链；交接、换手、放置写清接触者、接触方式、落点 |
| 终点 | 可验证的结束状态，能成为下一镜的可信起点 |
| 声音 | 台词 / 画外音 / 环境声，含估时依据 |

## 动作量

数一下这一镜要观众看清几件事，按镜长判断每件有没有足够时间被看清。**视频模型不会删掉多出来的动作，而是把它们压到看不清。** 放不下就删、合并或拆镜。同一动作不跨镜重复发生（峰值处有意的冲击重复除外）。

## 冻结关键帧

- **只投影起点**：删掉终点才出现的文字、动作、姿态或道具状态；
- 只写这一瞬间能看见的东西：主体、构图、机位、光、连续性锁的锁面；
- 镜头职责落在收尾那一下时，可另写收尾关键帧，规则对称（删掉起点才有的东西）；
- 全集用同一句画风、每个场景同一句光与色温，像同一部片；
- 近景挂地点参考图常被拉宽成中远景：写具体取景（画面切在哪、脸在画面哪里），仍偏宽就不挂地点图，把背景写进正文；
- 关键帧里点名的人物、道具，必须出现在本镜的「视觉依据」里；只描述不点名的入画人物也要自己读出来补上。

## 切镜规则

- 切镜必须带来信息、权力、情绪、空间或节奏变化，同义重复镜头删掉；
- 对话场按正反打 + 关键反应切；关键动作插特写；进场用「全景交代 → 中景动作 → 近景反应」三件套；
- 竖屏优先保证主体和反应可见，关键信息的可读性优先于装饰性运镜；
- 同框 ≤3 人，多了写拆解（正反打、让人出画或背身）。

## 构图量化（没有分镜图时就是构图的全部来源）

每段写 blocking（谁在左谁在右、间距），每切写焦距、机位高度、构图、视线落点、焦点、稳定性。
