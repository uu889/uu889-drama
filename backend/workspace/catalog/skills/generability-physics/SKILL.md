# 可生成性与物理

视频模型最常崩在：手和物体的接触、多人同框、精巧小动作、没有受力的运动、太多事同时发生。写提示词时主动避开。

## 动作写法

- **一段一个简单动作**：一个镜头只有一个主要动作，次级反应可以有，但不并行三件事；
- **写接触**：谁的哪只手、碰到物体的哪一段、怎么用力、物体怎么响应（「右手握住门把手下压，门向内打开」）；
- **写支撑与重心**：站在什么面上、重心往哪边移、落地时膝盖弯曲缓冲；
- **物体有来处**：道具出现之前在哪里（桌上、口袋里、对方手里），不凭空出现；
- **只写常见动作**：模型见过千万次的动作稳定；「睫毛轻颤、指尖一挑、伸篙一挡」换成可见的大动作或反应镜；
- **心理状态不默认翻译成身体症状**：不要一律写发抖、瞳孔放大、冷汗，写人物正在处理的对象和选择。

## 打戏与特效：四段式

1. **蓄力**：重心下沉、后拉、能量聚集；
2. **释放**：动作打出、特效发射；
3. **接触定格**：命中瞬间短暂停顿（几帧），冲击波 / 火花；
4. **恢复**：动作收回、被击者受力后退或倒地、尘埃落下。

被击中的一方要「承受」：身体后仰、脚步后撤、物体碎裂。只写攻击不写受击，画面会发飘。

## 同框人数

同时说话或做动作的人 ≤3；更多人时用正反打、让人出画或背身、把群众写成环境。

## 去「AI 光泽」

- 皮肤写真实纹理（毛孔、细小瑕疵），不写「完美无瑕」；
- 光写来源和方向（窗、台灯、霓虹），不写「电影级光照」「大师光」；
- 材质写能被光验证的表面（起球的毛料、洗得发白的棉、湿透贴身的布）；
- 必要时直接写「遵守物理，避免合成的 AI 光泽」。

## 镜头语法

- 以建立镜头交代空间；避免两个特写之间直接硬切；
- 运镜和人物动作不争注意力，复杂运镜要有叙事理由；
- 不要在同一句里要求一镜到底和不相关的角度变化。

## 心理预期

长片级制作的抽卡比例很高（公开案例约 64 次生成选 1 个镜头）。保留多个版本，一次只改一个变量，记录第一个可见失败。
