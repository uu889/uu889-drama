# 剪辑硬规则

## 只有这些是必须遵守的（生产正确性）

1. **字幕最后叠**：在所有叠层之后，否则会被叠层盖住，而且不报错；
2. **逐段抽取 → 无损拼接**：每段单独抽取处理，再 `-c copy` 拼接，不要一个滤镜图做完，否则加叠层时每段被重复编码两次；
3. **每个切点 30ms 音频淡入淡出**：`afade=t=in:st=0:d=0.03, afade=t=out:st={时长-0.03}:d=0.03`，否则每个切点都有爆音；
4. **叠层时间对齐**：叠层用 `setpts=PTS-STARTPTS+T/TB` 把动画第 0 帧移到窗口起点，否则会看到动画中段；
5. **字幕用成片时间轴**：`成片时间 = 词开始 − 段开始 + 段偏移`，否则拼接后字幕错位；
6. **不在词中间切**：切点吸附到转录的词边界；
7. **切点留余量**：30–200ms（转录时间戳常漂 50–100ms），快节奏取紧，电影感取松；
8. **用词级逐字转录**：不用句级 SRT（丢掉了亚秒级停顿信息），不归一化口头禅（丢掉剪辑信号）；
9. **转录按素材缓存**：素材没变就不重新转录；
10. **先提策略再动手**：4–8 句话说清结构、取哪条、剪辑方向、动画计划、调色方向、字幕样式、预估时长，等确认。

其余（字体、颜色、时长、节奏、转场手法）都是例子，按素材和用户要求自由发挥：分屏、画中画、下三分之一身份条、反应镜、变速、定格、J-cut / L-cut 都可以。

## 短剧剪辑单

逐镜写：

- **入点 / 出点及理由**：为什么从这一帧开始、在这一帧结束（动作完成、反应落地、台词说完）；
- **可用带**：这条生成素材哪一段能用、哪一段崩了；
- **镜序**：是否和分镜一致，改了要写为什么；
- **台词完整性**：台词有没有被切掉、有没有模型自编的多余台词；
- **未采用镜头**：逐个写镜号和理由（不接受「001 至 009」这种范围写法）。

## 声音

- 字幕逐字取自剧本，不用模型听写的版本；
- 统一响度（短视频平台常用约 -14 LUFS）；
- 配乐在有人说话时自动压低（sidechain），音乐循环到成片长度并淡入淡出。

## 自检（给用户看之前）

在成片的每个切点 ±1.5 秒抽帧 / 看波形，检查：跳帧、黑帧、冻帧、爆音、字幕被遮挡、字幕错位。有问题修了重渲染，最多三轮；自己不会交付的版本不要给用户看。
