# MiniMax H3 视频提示词

## 结构：同一条正文、一次提交

```
integrated_multimodal_description: [Shot 1] 景别、机位、运镜。场景与人物外观。动作从起点到终点。
[Shot 2] At 00:04.500, the camera cuts to … 下一切的画面与动作。
overall_soundscape: 环境底声 → 主要声音事件 → 收尾声音。
non_diegetic_music: 配乐风格、速度、乐器、起伏；不需要配乐写 N/A。
```

- `[Shot k]` 的切点时刻由分镜秒数推出，**一个字符都不能漂**；每个镜头独立一行；
- 参考图在正文里按挂图顺序叫 `<Picture 1>`、`<Picture 2>`（UU889 里写 `@图片N` 会自动换成这个标签）；
- 有角色主体时可用 `<Subject N>` 先定义再引用；拆开提交后面就没有指代对象，所以整段一起提交；
- 台词逐字进 `<d>[Chinese] …</d>` 块，只出现一次；动作段按时间和说话人引用，不再抄一遍台词。

## 选生成路径

| 任务 | 用什么开始 | 提示词补什么 |
|---|---|---|
| 新场景 | 纯文本 | 主体、动作、运镜、声音 |
| 让已有构图动起来 | 首帧 | 什么动、什么不动 |
| 到达指定构图 | 首帧 + 尾帧 | 两帧之间有动机的过渡 |
| 跨镜保持身份 | 脸、服装、地点**分开**的参考 | 每张参考的职责 + 本镜动作 |
| 按规划运镜渲染 | 预演视频 + 质感参考 | 保持几何和运动，只换外观 |

## 写一个镜头（shot brief）

```
SUBJECT：一个可识别主体 + 必须保持的少数细节
SETTING：地点、时间、材质、光
ACTION：开场状态 → 一个变化 → 结束状态
CAMERA：景别、一个运动、什么始终可见
TIMING：按所选时长排的短时间节拍
SOUND：台词、前景音效、环境、配乐优先级
CONTINUITY：身份、服装、几何和参考的职责
AVOID：两三个具体的失败
```

时间是预算：5 秒 = 开场姿势 + 一个动作 + 简短结尾。写「手接触把手、拉、松开」，不写「极其电影感的开场」。有冲击写准备和恢复；有文字就短、机位静止、留阅读时间。

## 常见修复（一次只改一个变量）

| 症状 | 下一次改什么 |
|---|---|
| 切镜后脸变了 | 减少切镜，给一张干净的正脸参考 |
| 手穿过道具 | 放慢交互，写接触和松开 |
| 第一人称视角跑掉 | 列出允许可见的元素，删掉冲突的角度 |
| 文字闪烁 | 缩短文字，放在一个物体上，给阅读停留 |
| 动作发飘 | 写支撑面、重心转移、落地 |
| 同时发生太多事 | 拆成几个镜头后期剪 |
| 长片丢连续 | 规划边界帧，维护参考与状态记录 |
| 口型落在别人脸上 | 说话人先交代画内外与音色，其他正脸写明闭嘴 |

## 迭代记录

每次生成记下：端点、日期、提示词版本、输入素材、时长 / 分辨率 / 画幅、种子、尝试次数、输出、**什么有效、第一个可见失败**。一次漂亮的重抽不代表成功率。
