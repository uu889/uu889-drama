# 对白估时与拆镜

镜长先由声音决定，再由动作补足。秒段加总正确不代表台词说得完。

## 语速参考

| 场景 | 估算 |
|---|---|
| 剧本层通用估算 | 4.5 字/秒（去掉标点计字） |
| MiniMax H3 中文实测小样本 | 约 4.1 个可发声字/秒，更密会赶词或被静默截断 |
| 动作节拍 | 约 2.5 秒/拍 |
| 换人说话 | 每次 +0.8 秒 |
| 开场 / 收尾 | +0.5 秒 / +1 秒 |
| 画面文字 | 按观众每秒读几个字另算停留时间 |
| 英文 | 按词计，约 2.5–3.7 词/秒 |

数字和缩写按实际读法估。估时依据简写在本镜「声音」里。

## 规则

- 先估完整发声时间，再安排不能和台词重叠的动作、停顿和末尾反应；
- **台词 5 秒的镜头给 6–8 秒，不给 10 秒**：多出来没人说话的时间，视频模型会自己编台词、胡言乱语；
- 超过 3 秒的无台词时间，写成具体可见的动作或反应（起身、递东西、沉默对视、整理衣角）；
- 台词装不下就**拆镜**，拆到同场景的连续镜头里；不要把短对话塞进长镜头，也不要让模型赶词；
- 一句太长的台词按句号、逗号断开，后半句写成「某某继续说：「…」」放进下一镜；
- 镜长超过目标模型单段上限（通常 15 秒）必须拆；
- 视频提示词只能照抄分镜已确定的时长，不能在提示词阶段暗改。

## 口型落错人怎么办

- 说话人第一次出现时交代画内 / 画外与音色，台词紧跟他的动作句；
- 台词期间画里还有别的正脸时，写明那个人闭嘴不说话；分镜能安排时先让他出画或背身；
- 生成后仍要核对，样本小，规则不是保证。
