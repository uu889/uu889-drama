# 剧本体检

对一份已有剧本逐条跑质量门，输出诊断书。**只诊断不改写**，除非用户要求修改。

## 检查项

| # | 门 | 判定方法 | 不通过时怎么改 |
|---|---|---|---|
| 1 | 每集时长在目标 ±15% | 台词按 4.5 字/秒（去标点计字），动作节拍按 2.5 秒/拍 | 超了先砍动作节拍再压台词；欠了补冲突 |
| 2 | 单句台词 ≤35 字 | 逐句数字 | 拆成两句，中间插动作或反应 |
| 3 | 说话人合法 | 说话人在本场人物里，或标 VO / OS | 补进场景人物或改成画外 |
| 4 | 钩子落纸 | 每集写明开场钩子 | 补钩子 |
| 5 | 钩子在前 3 拍兑现 | 钩子的具体事件出现在全集前 3 个节拍内 | 把钩子事件提到开场，冷开场 |
| 6 | 结尾悬念落纸 | 每集末有悬念或停在峰值 | 补悬念 |
| 7 | 每场至少一个动作节拍 | 场内有非台词的可见动作 | 补一个推进因果的动作 |
| 8 | 动作叙述不混引号台词 | 动作行里没有「…」对白 | 拆成单独台词行 |
| 9 | 爽点认领 | 大纲给本集的爽点在剧本里有对应戏 | 补戏或调整大纲 |
| 10 | 角色 / 场景 / 道具对账 | 剧本用到的都在资产表里 | 补资产或改剧本用已有的 |
| 11 | 同框人数 | 同时说话或动作的人数 ≤3 | 拆成正反打或让人出画 |
| 12 | 精巧动作预警 | 「睫毛颤、指尖一挑、伸篙一挡」类动作 | 换成可见大动作或反应镜 |

## 输出格式

```
## 体检结果：EP001（预估 118 秒 / 目标 120 秒）
✓ 1 时长  ✓ 2 单句长度  ✗ 5 钩子位置 …

### ✗ 5 钩子位置
- 问题：钩子（经理当众泼水）出现在第 7 拍。
- 建议：把泼水挪到开场第一拍，原第 1–6 拍的铺垫压成 2 拍放到泼水之后。
```

最后一句话总结：几项通过、几项不通过、最该先改哪一项。门没过不阻止交付，要的就是把问题摆出来。
