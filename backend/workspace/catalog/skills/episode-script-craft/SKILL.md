# 短剧单集剧本

把单集意图写成可表演、可拍摄、会改变故事状态的剧本。**剧本管戏，分镜管拍**：这里不写镜号、景别和生成提示词。

## 先锁定四件事

1. 本集承诺给观众的观看体验（爽、虐、甜、悬疑、笑）；
2. 谁现在要什么、阻力是什么；
3. 本集兑现什么；
4. 结尾停在哪个状态（悬念 / 峰值 / 余韵）。

## 写作规则

- **第一拍就是钩子**：冷开场，钩子在全集前 3 个节拍内具体发生（危机、冲突、反常已经在画面里），不是在为它铺垫。
- **每场必须改变一样东西**：信息、权力、关系、情绪、物理状态或风险。没变化的场删掉或合并。
- **核心阻力的转向要有可追溯的原因**：事实、筹码、权限、代价或人物行动，不能只靠对手突然不反应。
- **对白必须在做事**：争取、回避、试探、逼迫或重新定义关系。写完读一遍，删掉不能转成演员一个动作或表情的句子（用户带来的原文不按这条删）。
- **能演的不说**：不用 VO、内心独白或解释替代行动，已经演清楚的机制不再说一遍。
- **每场至少一个动作节拍**：纯对白的场是广播剧，AI 生成时没有画面可写。
- **动作只写常见动作**：「挑担上船、搭手卸担、推门、递文件」是模型见过千万次的；「伸篙一挡、睫毛轻颤」这种精巧动作生成容易崩，换成可见的大动作或反应。
- **单句台词一口气说完**：≤35 字；长独白按句拆开，中间插动作或反应。
- **谁的话像谁**：口头禅、句长、用词随人物身份和性格变化。
- **配角按戏份给策略**：承担主要冲突的角色有自己的目标和判断；事务性角色保持简洁，不为了「丰满」硬加秘密或反转。
- **结尾**：可以推进、留白、反讽或停在峰值；项目要求「停在峰值」时不接余韵。

## 格式

```
# EP001 集名
## EP001-SC001 内 · 地点 · 时间/天气
动作描述（只写看得见、听得见的）
角色（可选表演提示）：台词
[VO] 画外音 / 内心独白（谁的写在提示里）
[OS] 画外但在场的人声
[SFX] 有叙事作用的声音
[画面文字] 屏幕、手机、招牌上需要读出来的字
[连续性] 容易在下游丢失的状态交接（伤、湿、持物）
```

不要把含冒号的动作叙述误写成对白。

## 时长

按 4.5 字/秒估台词、每个动作节拍约 2.5 秒，加起来在目标时长 ±15% 内。写超了先砍动作节拍再压台词；写欠了补冲突不注水，不加寒暄。

## 交稿前静默反查

只读剧本：观众能否接收到本集承诺？人物行动有没有因果？题材语气一致吗？自检时如果添加了题面没要求的机关、数字、记录链，撤掉。「去 AI 味」是定点修订，不抹平作者个性。
