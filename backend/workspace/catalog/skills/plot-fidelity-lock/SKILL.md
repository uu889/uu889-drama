# 剧情保真锁

**总纲：只导演，不编剧。** 进入分镜、视频提示词、配音稿阶段后，剧本就是事实来源。你可以决定「怎么拍」，不能改变「发生了什么」。

## 可以做

- 拆分、合段、计时、镜头化、站位化；
- 把剧本里已有的动作写得**可见**（例：「擦手」→「纸巾接触掌心、擦过手指」）；
- 补充不改变剧情事实的物理、摄影执行细节：景别、机位、焦点、光线的可见结果、已有碰撞对应的拟音。

## 五类绝对禁止

对剧本里的每个事件，禁止：

1. **新增**：剧本没写「开盖 / 起身 / 递给 / 回头 / 拿起」，不为了顺畅自己补上；
2. **删除**：已有的动作、台词、反应、停顿、空镜，不为了时长或「表演克制」删掉；
3. **替换**：剧本是 A 动作，不改成看起来更合理的 B 动作；
4. **改归属**：剧本写「家长」就不擅自指定成「爸爸」；谁说、谁做、谁拿、谁被碰都保持原样；
5. **改顺序 / 改因果**：不把后面的行为提前，不为后面的状态补一个剧本没有的前置动作。

## 剧情事实的优先级

冲突时按这个顺序认定什么是事实：

1. 用户最新一条明确修改指令；
2. 当前剧本 / 原文 / 时间轴；
3. 用户确认过的角色、场景、道具设定；
4. AI 之前生成的提示词、摘要、补充说明。

**AI 上一轮自己补出来的内容，永远不能反过来升级为剧情事实。** 例：上一版提示词擅自写了「先从盒子里取出道具」，原剧本只写「使用道具」，这一版不能因为「连续性」继续沿用这个取出动作。

## 具体化的边界（四条全部满足才允许）

- 具体化内容直接包含在原动作的物理执行里；
- 不新增剧情决定、道具状态变化或人物关系；
- 删掉这条描述后剧情事实完全不变；
- 不让观众获得原文没有的新信息。

## 自检

交付前逐镜对照剧本问三句：这一镜有没有剧本里不存在的事件？剧本里这一段的事件是否都还在、顺序对不对？每个动作的执行者是不是原来那个人？有任何一条答「否」就改回来。需要改剧情时，停下来告诉用户，交回编剧阶段处理。
