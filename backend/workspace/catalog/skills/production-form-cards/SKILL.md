# 制作形态卡

画风不只是一句风格词。选定制作形态后，身份靠什么识别、哪些东西会动、光和材质怎么写，都跟着变。

| 形态 | 身份锚点 | 必须逐镜传递 | 运动预算 | 光与材质的可执行写法 | 最常见失效 |
|---|---|---|---|---|---|
| **Q 版** | 头身比 + 大色块 + 一个被放大的记号（眼镜、呆毛、工牌） | 头身比与角色间相对尺度、主色块、放大记号、手中物 | 一镜一个因果单位，只动执行因果的那只手或物体 | 平涂 + 两段明暗 + 高饱和主色；「危险物用画面里唯一的高饱和红」 | 全员持续弹跳，因果读不出来 |
| **二维动态漫** | 轮廓剪影 + 线条特征 + 固定色块（剪影测试：填成纯黑还认得出） | 轮廓与色块、阴影分区、描边规则、本镜可动层 | 默认限动画：只让承担因果的那一层全动，其余定帧或局部循环 | 色块关系（主色 / 阴影色 / 高光色、硬边或渐变），不写三维光照词 | 所有图层同时轻微飘动 |
| **国漫二次元** | 可枚举的结构差异：脸型、眼型、瞳孔高光形状、发色渐变位置、固定配件 | 脸 / 眼 / 发结构与色卡、氛围色温、高光落位 | 情绪转折镜给全动作，对白镜用口型、眨眼、发梢循环 | 光源色 + 反射光色 + 高光形状 + 阴影边界硬度 | 全剧人物趋同；氛围色吃掉瞳色发色 |
| **实拍** | 造型状态：发型走向、妆面、服装穿法（袖挽到哪、扣到第几颗）、随身物位置 | 造型整洁度、湿 / 污 / 伤的程度与位置、手中物、光源时段 | 默认全动作，要限制的是同镜并行动作数和道具交接手数 | 来源 + 方向 + 遮挡 + 反射 + 叙事用途 | 把情绪写成通用症状；衣着自动变整齐 |
| **水墨笔触** | 起笔收笔构成的形 + 不可散的墨记号（点名哪些边缘绝不洇化） | 不可散轮廓、浓淡层级、手中物、必要地理、留白方位 | 极低：大部分画面 hold，只动少数墨迹 | 墨的六项：浓淡（注意力）、干湿（时间与用力）、飞白（速度）、洇化（情绪扩散）、留白（未知）、笔势（动作方向） | 「水墨感」吃掉地理和手中物 |
| **风格化三维** | 比例 + 剪影 + 骨骼能达到的姿势范围 | 比例剪影、材质分区、接触点、光向与体积介质、轴线 | 可全动作，但摄影机最贵，运镜必须有动机 | 表面如何响应光（粗糙 / 光滑、高光是圆点还是拉长条）+ 接触与重量 | 脚离地、穿模、持物无来源换手、只靠文字时滑向实拍 |

## 怎么用

1. 项目开始时选一个形态，写进项目的视觉方向；
2. 角色设计按该形态的「身份锚点」写，资产表多一栏「锚点」；
3. 分镜和视频提示词按「运动预算」决定哪层动、哪层定；
4. 「光与材质」只用可执行写法：「精致」「唯美」「电影感」「高级灰」「氛围感」都不是规格，写进去等于没写；
5. 审查时对照「最常见失效」逐条看。

**删掉风格名称后，如果线条、色层、阴影边缘、材质和空间写法没有任何变化，这个方向仍只是标签。**
