# 视觉方向定调

在正式分镜之前，把「我想要某种感觉」变成几张可比较的代表帧，让人物、场景、高压力戏共用一套视觉语言。

## 什么时候值得做

- 已选好形态，但材质、光色、边缘、画面密度仍停留在形容词；
- 人物图、场景图、分镜各自成立，但看不出来自同一部作品；
- 某个画风适合静态设定图，不确定能不能撑住表演和冲突。

## 三类代表帧

1. **人物表现帧**：身份锚点、肤质 / 线条、目光和细小表演是否仍可读；
2. **核心地点帧**：空间层级、材质响应、光源逻辑、色彩关系能否复用；
3. **高压力场景帧**：遮挡、冲突、注意中心能否承载，而不只适合静态展示。

## 每个候选方向写四件事

- **稳定项**：跨人物、地点、压力场景都要保留的形状语言、材质处理、色彩层级、阴影边缘、景深倾向、画面密度；
- **可变量**：允许按场次变化的冷暖、对比、留白、光比；
- **叙事职责**：这些选择帮观众识别什么、感到什么；
- **失效信号**：身份锚点被吞、群像层级打平、冲突戏只剩氛围。

## 风格手册（可选，写成项目设定）

- 色板：主色、强调色、背景色、文字色、弱化色（写十六进制）；
- 构图与质感倾向；
- 字体（片头、字幕、系统面板）；
- 动效：转场方式、镜头停留秒数范围；
- 声音：旁白风格、配乐情绪与音量、音效风格；
- 生图前缀与负面词；
- **一致性锚点清单**：每一场都必须出现的 3–6 条可观察规则（例：「每个场景都有深绿与暖金」「柔和水彩边缘，没有硬数字线条」）。

## 边界

风格帧不能发明或覆盖角色身份、场景地理、剧情事实；风格参考图只控制色彩、材质、光、景深、密度。用户选定后把稳定项写进项目视觉方向，之后所有关键帧用同一句画风。
