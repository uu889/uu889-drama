# 短剧钩子与节奏

## 开头 3 秒
- 第一句台词或第一个画面就给冲突：被打脸、被背叛、身份暴露、生死危机，选一个。
- 不铺垫世界观，不做自我介绍；背景信息藏进冲突里的台词带出来。
- 主角在开场就要「被压」——处境越低，后面的反转越爽。

## 节奏
- 每 15~30 秒一个小反转或信息增量（新身份、新证据、新敌人、局势翻转）。
- 一场戏只办一件事；场景切换要快，台词短句为主，每句 ≤ 20 字。
- 情绪曲线：压 → 更压 → 小反击 → 大反转，单集至少一次「爽点」兑现。

## 集尾
- 停在悬念最高处：真相揭开一半、危机刚出现、关键人物登场。
- 最后一句台词或最后一个画面留问题，不留答案。

## 台词
- 口语化，能直接念出来；人物身份不同，说话方式要有区别。
- 关键台词要能当字幕单独成立（金句、反转句）。
