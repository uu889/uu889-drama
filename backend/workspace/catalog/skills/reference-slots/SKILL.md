# 参考图槽位

视频模型能收的参考图有上限（Seedance 2.0 约 9 张、MiniMax H3 9 张、aiask Grok 1.5 最多 14 张），每张图都要说清楚它在本镜负责什么。

## 槽位格式

```
参考图N · <文件>《中文名》（用途：…；控制：…；不得控制：…）
```

**用途**九选一：

| 用途 | 控制什么 | 典型 |
|---|---|---|
| 起始帧 | 起始构图、本镜开场画面 | 本镜冻结关键帧出的图 |
| 结束帧 | 结束构图（必须同时有起始帧） | 收尾关键帧 |
| 身份 | 脸、发型、体型 | 角色锚点、大头照 |
| 造型状态 | 本集服装、伤、湿、脏 | 换装后的定妆照 |
| 地理 | 场景布局、固定元素 | 场景白板图 |
| 构图 | 景别、主体位置 | 构图草图 |
| 尺度 | 物件与人的大小关系 | 尺度参考 |
| 效果 | 特效形态 | 特效参考 |
| 风格 | 色彩层级、材质、光、景深 | 场景定调图 |

「不得控制」写清楚这张图**不能**改变的事：例如场景定调图「不得控制：构图、人物身份、剧情状态」；角色锚点「不得控制：姿势、表情、背景」。

规则：

- 一张图只占一个槽位；承担两件事时用途写主要的，另一件写进「控制」；
- 一镜最多一张起始帧、一张结束帧；
- 只挂本镜**可见**、且确实需要稳定的图，不按资产数量凑槽位；
- 上一镜的绑定不因为「角色还在这场戏里」就自动顺延。

## 组合即模式

- 只有起始帧 → 首帧图生视频；
- 起始帧 + 结束帧 → 首尾帧；
- 起始帧 + 人物 / 地点 / 道具图，或只有这些图 → 多图参考生视频。

## 超出上限时的取舍顺序

按「失去它的代价」从高到低保留：

1. 起始帧；
2. 正在说话或做主要动作的人物（近景说话镜可多挂一张该角色大头照）；
3. 必须认得出的道具；
4. 地点；
5. 其余入画人物；
6. 定调图。

被放弃的那些，把必要事实写进提示词正文。

## 缺图时

**点名了模型 ≠ 选择文生视频。** 项目里没有所需的图时，写成「挂图计划」（要挂哪张、什么顺序、每张管什么），提示词照常按图生视频写；只有用户明确说不用图，才改成文生视频，并在提示词里把人物、造型、地点、光线的必要事实写全——文生视频不能写「保持已有外观」，因为模型没收到可保持的图。
