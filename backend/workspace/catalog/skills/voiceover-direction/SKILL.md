# 配音导演

## 选音色

- 先列角色和音色对照表：角色、性别、年龄段、性格、音色名、语气（例：妈妈=温柔女声、小明=男童、爷爷=老年男声）；
- 同一部剧里一个角色始终用同一个音色；主要角色之间音色要拉开（音高、语速、质感）；
- 声音克隆只复刻用户本人或已获授权的声音；参考录音 3–10 秒、安静、单人、正常语速、无背景音乐，部分模型版本必须同时给参考文本。

## 旁白和对白怎么合成

1. 先写配音稿：每句标说话人、语气、情绪；
2. **按句切分、逐句合成**，得到每句的真实时长和时间轴（精确到句）；
3. 切掉每句首尾多余静音，句间停顿由程序控制；
4. **按配音真实时长定镜头长度**，画面不够长就延长镜头或补反应镜；
5. 视频片段只保留环境音，合成时挂上配音、自动压低原声和配乐；
6. 生成式语音模型（会自带音乐音效的）要明确要求「只有人声，无音乐无音效」。

## 口型取舍

| 镜头 | 用什么声音 |
|---|---|
| 正面说话、能看清嘴型 | 视频模型的同期人声（口型同步） |
| 背影、远景、画外音、电话、蒙太奇、动画角色 | TTS 配音 |
| 系统音 / 电子提示 | TTS + 电子音质感，标为画外 |

正面说话镜要用同期声时，在视频提示词里写清说话人、台词逐字、语气，并要求画面里其他正脸闭嘴。

## 参考音频

目标模型支持参考音频时，给说话的角色挂一段他的声音参考，写明用途是「音色」，**不得控制台词、语气、情绪**。

## 失败兜底

配音服务可能未开通、余额不足、本地服务没启动；按顺序自动换下一个已配置的服务，并在结果里说明实际用了哪个。
