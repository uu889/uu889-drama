# キャラクター最終プロンプト（左側：正面顔クローズアップ ＋ 右側：三面図）

生成するのはキャラクター設定参照画像（character reference sheet）1枚。構図は固定：

- **左側：正面顔クローズアップ**——頭部と肩部の正面アップ。顔立ち、髪型、肌質がはっきり見え、顔の識別性のアンカーとなる
- **右側：正面、90度側面、背面の3枚の等高全身ビューを並列表示**——同一キャラクターの3つの全身ビューを等高で並べ、頭頂と足裏を揃える

**中核原則：一貫性 ＞ 美しさ。** この画像は後続のすべてのキャラクター画像・動画参照の外見のアンカーであり、中立的で、明瞭で、再利用可能でなければならない——単独の1枚としての芸術性を追求しない。

## 出力構造（この順序で1段落の連続した記述を組み立てる。言語はセッションの言語指令に従う）

```
キャラクター設定参照画像。左側は正面顔クローズアップ、右側は正面・90度側面・背面の3枚の等高全身ビューを並列表示。
クローズアップと全身ビューはすべて同一キャラクター。全身が画面に収まり、中立的なA字の立ち姿。3枚の全身ビューは等高で並び、頭頂と足裏が揃っている。
[年齢感 ＋ 性別感 ＋ 体格]、[顔立ちの特徴]、[髪型]、[服装 ＋ アクセサリー]。
正面顔クローズアップと3つのビューの顔・髪型・服装は完全に一致。
純白の背景、斜め前方からの柔らかなスタジオキーライトで明暗のグラデーションが自然で立体感がある、ピントがはっきり合い画面全体がシャープ、きめ細かく自然な肌の質感、髪は一本一本まで明瞭、服の生地の織り目・縫い目・しわがはっきり見える、高精細、高解像度
```

## 記述順のルール

**最も識別しやすい特徴を前に置き**、この順序で `appearance`（容姿）と `styling`（装い）の各キー要素を漏れなく落とし込む：

1. 識別のアンカー：年齢感（例：「二十歳そこそこ」）、性別感、体格（身長・肥痩、姿勢の癖）
2. 顔立ち：輪郭、目、その他の顕著な特徴（傷跡、ほくろ、眼鏡など）——正面顔クローズアップは特にこの部分の描写に依存する
3. 髪型：色、長さ、スタイル
4. 服装：デザイン、色、素材、状態（例：「袖口にはんだの跡のある皺だらけの作業服」）
5. アクセサリー：識別性のあるものだけを書き、詰め込まない

キャラクターの性格特性は外的な雰囲気と表情の描写に変換する（例：「憔悴」→「疲れ切った眼差し、肩がわずかに落ちている」）。性格を表す語彙を直接登場させない。

## 構図と一貫性

- 左側の正面顔クローズアップ：正面からカメラに向き、中立的な表情、頭頂から肩まで完全に画面に収める
- 右側の3枚の全身ビュー：同一キャラクターの正面、90度側面、背面。**等高で並び、間隔は均等**、頭頂と足裏が同一水平線上にある
- クローズアップと3枚の全身ビューは同じ顔、同じ髪型、同じ服装でなければならない——「正面顔クローズアップと3枚の全身ビューの顔・髪型・服装は完全に一致」と明確に書き出す
- 中立的な立ち姿、自然な表情——参照画像として再利用しやすくするため
- 柔らかなスタジオ光。キーライトは斜め前方から当て、明暗のグラデーションを自然にして顔と体の立体感を出す。劇的で強い光影は使わない（参照画像はあらゆるシーンで使える必要がある）が、方向のないフラットな光も使わない（嘘っぽく見える）
- 出力はセッションの言語指令で指定されたターゲット言語を使い、無関係な語彙を混ぜない

## 画質とディテール（ぼやけない・嘘っぽくしない）

画面がぼやけて嘘っぽく見えるのは、たいていプロンプトが漠然としていて「高品質」のような空疎な語しか書いていないためです。次のように書きます：

- **ピントと鮮明さ**：「ピントがはっきり合い、画面全体がシャープ」と明記する。被写界深度・背景ボケ・ソフトフォーカス・もやは書かない（参照画像はすべての部分が読み取れる必要がある）
- **質感を具体的に**：主要な要素ごとに目に見える物理的な質感を書く——肌（きめ細かく自然な肌の質感）、髪（一本一本が分かれ、ツヤの階調がある）、布（生地の織り目・縫い目・しわ・擦れ）、金属 / 革 / 木などの小物（傷、使い込んだ艶、反射）。「コート」より「チャコールグレーのウールコート、細かな綾織りの生地、肘に軽い毛玉」のほうが良い
- **光には方向を**：柔らかい＝平坦ではない。キーライトの方向と明暗のグラデーションを書く（例：「柔らかなキーライトが左前方から当たり、顔の右側に自然な影のグラデーション」）。方向のないフラットな光がいちばん嘘っぽく見える
- **最後に画質アンカー**：高精細、高解像度——最後に一度だけ書く。「傑作、8K、最高品質」のような空疎な語を重ねない
- 「完璧で傷一つない」「陶器のように滑らか」など、美肌加工・プラスチック感を招く語は書かない

## 禁止事項

- 動的なポーズ、誇張された表情、手に持った小道具、他人との共演
- 身体の裁切（全身ビューは必ず full body で頭頂から足裏まで完全に画面に収める；クローズアップは頭部と肩部を完全に画面に収める）
- 文字、ラベル、透かし、署名
- 強い影、カラーの背景光、背景の小道具
- 被写界深度のボケ、ソフトフォーカス、もやのかかったフィルター。美肌加工、プラスチック / 蝋人形のような質感

## 保存

`save_character_final_prompt` を呼び出す：prompt パラメータにスタイル語を含めない。**プロジェクトのビジュアルスタイルはツールが最終プロンプトの先頭へ自動注入する**。
