# 소품 최종 프롬프트(화이트 배경 단품 · 표준 제품 사진)

생성물은 화이트 배경 단품 이미지(product shot)입니다: **표준 제품 사진 시점**을 사용하고, 화면에는 소품 자체만 있으며 순백 배경 위에 고립되어 놓여 있습니다. **다른 어떤 요소도 섞이지 않습니다** — 다른 물건 없음, 인물 없음, 장면 환경 없음, 손에 쥔 모습 없음.

세 가지 엄격한 요구 사항:
1. **물건 각 부분의 비율이 정확할 것** — 과장, 변형 또는 스타일화된 늘이기 금지. 소품의 상대적 크기 관계가 실제와 같아야 합니다
2. **가장자리가 완전할 것** — 소품 전체가 온전히 화면에 들어오고 사방에 여백을 두며, 어떤 부분도 화면 가장자리에 잘리지 않아야 합니다
3. **배경이 어떤 서사 내용도 담지 않을 것** — 순백 배경은 받침일 뿐, 장면감·줄거리 암시·장식 요소를 갖지 않습니다

## 출력 구조(이 순서대로 하나의 연결된 문장으로 조립, 언어는 세션 언어 지시를 따름)

```
단품 제품 이미지, 표준 제품 사진 시점, [소품명 + 재질/색상/형태/크기 + 사용감과 마모 디테일].
물건 각 부분의 비율이 정확하고, 순백 배경 위에 고립되어 놓여 있으며, 중앙에 온전히 들어오고, 가장자리가 완전하여 잘림이 없음.
배경은 깨끗하고 어떤 서사 내용도 담지 않으며, 다른 물건 없음, 인물 없음, 장면 없음.
부드럽고 고른 스튜디오 조명, 옅은 접지 그림자, 물건 전체에 초점이 맞고 가장자리가 선명, 재질 표면 디테일(질감, 긁힘, 마모, 반사)이 또렷하고 사실적, 고디테일, 고해상도
```

## 생성 규칙

- 소품 `name`(이름)과 `description`(물건의 외형)을 핵심으로 합니다: 재질, 색상, 형태, 크기, 사용감, 마모 흔적 등 물리적 디테일을 **항목별로 모두 구체화**합니다 — 이것이 소품 식별도의 원천입니다
- 표준 제품 사진 시점: 약간 위에서 내려다보는 3/4 시점(윗면과 측면을 동시에 볼 수 있어 가장 입체감이 있음); 납작한 소품(종이, 신분증, 사진)은 정면 위에서 내려다보는 평면 배치 사용
- 단품을 중앙에 온전히 배치하고 사방에 여백을 둡니다. 비율 정확, 가장자리 완전, 소품 본체를 자르지 마세요
- 부드럽고 고른 스튜디오 조명, 옅은 그림자, 고디테일
- 물건 자체만 묘사하고, 줄거리·캐릭터·용도를 언급하지 마세요(배경과 화면 모두 서사 내용을 담지 않음)
- 출력은 세션 언어 지시가 지정한 목표 언어를 사용하고, 무관한 어휘를 섞지 마세요; "영화적 질감"류의 단어는 쓰지 **마세요**(소품 이미지는 제품 사진이지 스틸컷이 아님)

## 화질과 디테일(흐리지 않게, 가짜 같지 않게)

- **초점**: "물건 전체에 초점이 맞고 가장자리가 선명"이라고 명시합니다. 피사계 심도, 흐림, 소프트 포커스는 쓰지 마세요
- **재질을 구체적으로**: 표면 질감, 긁힘, 마모, 손때 묻은 광택, 반사, 이음매를 하나씩 씁니다 — 소품이 진짜처럼 보이는지는 여기서 결정됩니다. "열쇠 하나"보다 "황동 열쇠, 톱니는 오래 써서 반짝이고, 손잡이에 잔 긁힘과 암녹색 산화 얼룩"이 낫습니다
- **부피감 있는 빛**: 부드럽고 고르되 방향이 있어 물체의 형태와 두께가 보이고, 아래에 옅은 접지 그림자가 있음
- **마지막 화질 앵커**: 고디테일, 고해상도 — 한 번만 씁니다. "걸작, 8K, 최고 품질" 같은 빈 단어를 쌓지 마세요

## 금지 사항

- 손에 쥔 모습, 인물, 다른 물건, 장면 환경이 화면에 들어오는 것
- 포장, 받침대, 진열대(소품 본체의 일부인 경우 제외)
- 텍스트, 워터마크, 서명(소품 본체에 인쇄된 글자·무늬는 유지하고 묘사 가능)
- 환경 반사광, 컬러 조명
- 과장된 원근, 변형, 비율 왜곡, 가장자리 잘림
- 피사계 심도 흐림, 소프트 포커스; 지나치게 매끈하고 질감 없는 플라스틱 같은 표면

## 저장

`save_prop_final_prompt` 를 호출합니다: prompt 파라미터에는 스타일 단어를 넣지 않습니다. **프로젝트 비주얼 스타일은 도구가 최종 프롬프트 맨 앞에 자동으로 주입합니다**.
