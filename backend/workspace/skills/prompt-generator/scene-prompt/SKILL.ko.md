# 장면 최종 프롬프트(광각 establishing shot · 인물 없는 빈 장면)

생성물은 **선명한 광각 establishing shot** 장면 이미지입니다: **인물이 전혀 없는** 순수 장면 빈 컷으로, **전경, 중경, 후경, 출입구, 바닥, 벽면 및 주요 비품의 고정된 상대 위치**를 온전히 보여주며, 공간 구조가 연속적이고 자기 모순이 없으며 재사용 가능합니다.

이 이미지는 해당 장면의 모든 컷의 배경 참조 앵커로 사용됩니다: 관객과 모델 모두 이 이미지 하나로 전체 공간의 배치를 읽을 수 있어야 합니다 — 어디로 드나드는지, 바닥과 벽면이 어떤 질감인지, 핵심 비품이 각각 어느 위치에 고정되어 있는지. 시점은 반드시 안정적이고 범용적이어야 합니다.

## 출력 구조(이 순서대로 하나의 연결된 문장으로 조립, 언어는 세션 언어 지시를 따름)

```
고정 카메라 광각 컷, 선명한 establishing shot, [장소 + 시대적 질감], [시간대].
전경([전경 요소]), 중경([중경의 주체 공간]), 후경([후경의 깊이])의 삼중 레이어 구도.
출입구([문/통로의 위치와 형태]), 바닥([바닥 소재와 상태]), 벽면([벽면 소재와 색상]).
[주요 비품과 그 고정된 상대 위치].
공간 구조가 연속적이고 자기 모순이 없음.
[광원 + 색온도 + 명암 대비], [분위기].
팬 포커스로 전경·중경·후경 모두 선명하게 초점, 바닥·벽·주요 집기의 재질 디테일(질감, 마모, 먼지, 반사)이 또렷이 보임, 사실적인 명암 계조와 접지 그림자, 고디테일, 고해상도.
장면에 사람이 없습니다, 빈 장면, 영화적 질감
```

## 공간 구조 규칙

공간은 반드시 **읽을 수 있고, 서로 맞물리며, 재사용 가능**해야 합니다:

- **전경**: 프레이밍/가림 요소(문틀, 테이블 모서리, 식물, 장비 가장자리)로 깊이를 만듭니다 — 구체적인 요소 1-2개를 쓰세요
- **중경**: 장면의 주체 공간과 핵심 비품(생산 라인, 침대, 카운터)
- **후경**: 공간의 연장(멀리 있는 벽, 창문, 복도, 도시 윤곽)
- **출입구**: 문, 계단, 통로의 위치와 형태가 명확해야 합니다(예: "화면 왼쪽의 철문 하나"). 이는 이후 컷에서 인물의 출입을 연출하는 근거가 됩니다
- **바닥과 벽면**: 소재, 색상, 상태를 구체화합니다(예: "콘크리트 바닥에 기름 얼룩", "벽면의 회반죽이 얼룩짐")
- **주요 비품**: 핵심 비품 2-4개와 그 **고정된 상대 위치**를 씁니다(예: "생산 라인이 벽을 따라 늘어서고, 끝에 바가 있음"). 비품 사이의 좌우/원근 관계가 자기 모순 없어야 하며, 물건 이름만 나열하지 마세요

## 인물(엄격한 규칙 · 최고 우선순위)

**장면 이미지에는 어떤 사람도 등장할 수 없습니다. 장면 자체만 남기세요.**

- 프롬프트에 인물을 묘사하지 말고, 인물과 관련된 어떤 내용도 언급하지 마세요
- 장면 묘사(prompt)에 등장하는 인물 정보는 모두 무시하고 프롬프트에 쓰지 마세요
- 프롬프트 끝에는 반드시 "장면에 사람이 없습니다, 빈 장면"을 포함해야 합니다

`prompt`(장면 묘사) 속의 비품, 시대적 질감, 핵심 시각 요소는 모두 구체화해야 합니다; `lighting`(장면 조명)은 구체화합니다: 광원 방향, 색온도의 냉난, 명암 대비(예: "천장 형광등이 차가운 백색광을 내고, 기계 아래로 날카로운 그림자가 드리움").

## 시점과 분위기

- 안정적인 정면 또는 약간 위에서 내려다보는 광각. 극단적인 위·아래 앵글, 어안 렌즈, 기울어진 구도 금지(고정 장면으로 반복 재사용해야 함)
- `location` + `time` 으로 시간대와 조명 톤을 결정합니다(낮/밤/황혼의 빛은 완전히 다름)
- 분위기 단어를 구체화합니다: "억압적" → "공기가 무덥고, 빛이 어둡고 낮게 가라앉음". 추상적인 감정 단어만 쓰지 마세요
- 출력은 세션 언어 지시가 지정한 목표 언어를 사용하고, 무관한 어휘를 섞지 마세요

## 화질과 디테일(흐리지 않게, 가짜 같지 않게)

장면 이미지가 흐리고 가짜처럼 보이는 것은 대개 집기 이름만 쓰고 질감을 쓰지 않았거나 빛이 평평하기 때문입니다. 다음과 같이 쓰세요:

- **팬 포커스**: "팬 포커스, 전경·중경·후경 모두 선명하게 초점"이라고 명시합니다. 얕은 피사계 심도, 배경 흐림, 소프트 포커스, 뿌연 효과는 쓰지 마세요(이 이미지는 모든 위치가 읽혀야 함)
- **재질을 구체적으로**: 바닥, 벽, 주요 집기에 눈에 보이는 질감과 흔적을 씁니다 — 나뭇결, 벽돌 줄눈, 타일 줄눈, 녹, 먼지, 물자국, 긁힘, 유리와 금속의 반사. "탁자 하나"보다 "칠이 벗겨진 낡은 판자 탁자, 가장자리가 닳아 하얗고, 컵 자국이 몇 개 남아 있음"이 낫습니다
- **사실적인 빛과 그림자**: 광원 방향, 명암 계조, 접지 그림자(물체가 바닥에 닿는 곳의 그림자)를 쓰고, 암부에도 디테일을 남기세요. 전체가 하얗게 날아가거나 회색으로 탁해지지 않게 합니다
- **마지막 화질 앵커**: 고디테일, 고해상도 — 한 번만 씁니다. "걸작, 8K, 최고 품질" 같은 빈 단어를 쌓지 마세요

## 금지 사항

- 어떤 인물이든 — **장면 이미지에는 어떤 사람도 등장할 수 없습니다. 장면 자체만 남기세요**
- 텍스트, 간판의 읽을 수 있는 글자, 워터마크, 서명
- 모션 블러, 움직이는 물체(장면 참조 이미지는 정지 상태로 안정적이어야 함)
- 상대 위치를 밝히지 않고 비품 목록만 나열하는 것(공간 구조는 연속적이고 자기 모순이 없어야 함)
- 얕은 피사계 심도, 배경 흐림, 소프트 포커스, 뿌연 화면; 지나치게 확산된 빛으로 인한 회색 탁함·하얗게 날아감
